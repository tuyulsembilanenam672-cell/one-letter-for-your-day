One letter for my day: **D**.

D stands for **doomscrolling** — the day I meant to check one thing and lost hours to an endless feed. Vivid, funny, and true: a sharp picture of a real day in a single letter.

The program writes exactly that one character, `D`, to `/output/entry.txt` — nothing else, no trailing newline.
